# Easy Street usable-release plan

Extend the verified chapter workflow into a bounded personal-course tool. Keep one localhost backend, local SQLite state, user-owned provider billing, source evidence, and the existing visual style.

## Acceptance criteria

- Build courses of one to six modules, with course-wide assessment totals and editable placement. Partition source coverage explicitly and generate one module at a time. Persist completed stages, budget reservations, and uncertain outcomes.
- Support readable PDF, DOCX, and UTF-8 TXT. Offer explicit selective local OCR when its optional local tools are available; never substitute a paid vision service.
- Restore exported course JSON into a new course without overwriting saved work. Missing originals remain visible and prevent unsupported regeneration. Restore prior versions and archive/unarchive courses.
- Group the editor and printable exports by module, with a proposed syllabus and separate answers. Preserve source references and manual edits.
- Provide a downloadable release containing the built frontend, first-run setup and start scripts, secret-free configuration examples, retained dependency notices, and plain setup/recovery directions.
- Exercise new behavior with meaningful automated regressions, production startup checks on Windows/macOS/Linux, desktop/mobile browser checks, and a small real multi-module provider run within the already approved $10 development cap.
- Publish only tested source and release artifacts; document actual results, known scope limits, and provider-review limitations.

Hosted accounts, public application hosting, LMS integrations, automatic grading, and additional providers remain outside this personal local release. Course and document size limits are explicit; this release does not promise arbitrary-book coverage or perfect factual grounding.
