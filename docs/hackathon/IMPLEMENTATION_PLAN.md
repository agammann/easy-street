2. Add an independent judging ASGI entry point. Each authenticated browser receives its own temporary directory, SQLite database and cache. 5. Prepare a one-instance container deployment, persistent accounting, liveness/readiness checks, low-balance status and a tested monitoring runbook. No services, agreements, financial commitments or monitoring are activated without approval.
6. Test both adapters and hosted boundaries with mocks, then inspect desktop/mobile workflows. Two local approved live runs and one hosted run have checked the authenticated model catalog and actual generation/support review, including revised prompt v2.1 and cache identity. Keep their measured results separate from mocks. Seven edits were saved in the second hosted cached copy while retaining raw evidence.
